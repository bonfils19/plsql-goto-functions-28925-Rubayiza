Reflections

1. GOTO Statement

I learned that the GOTO statement in PL/SQL can be used to change the normal sequence of a program. It allows the program to jump directly to a specific labeled section.

Basic Syntax

<<label_name>>
GOTO label_name;

The label identifies the location where the program should continue execution.

2. PL/SQL Functions

I learned that a PL/SQL function is a reusable block of code that can accept parameters, perform a specific task, and return a result.

Key Point

* A function must return a value.
* A procedure can perform an operation without returning a value directly.

Functions are useful because they allow the same operation to be reused in different parts of a PL/SQL program.

⸻

3. Exception Handling

I also learned how exception handling helps manage errors that may occur while a PL/SQL program is running.

Some useful commands include:

* WHEN OTHERS – catches exceptions that have not been handled by a specific exception handler.
* SQLERRM – provides a description of the error that occurred.

Exception handling makes PL/SQL programs more reliable because errors can be identified and handled instead of causing the program to stop unexpectedly.
